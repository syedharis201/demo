Flask To-Do List App
A simple and intuitive To-Do List app built using Flask, allowing users to efficiently manage their tasks with features like adding, editing, completing, deleting, and filtering tasks.

Features
Add new tasks.
Mark tasks as completed or undo them.
Edit and delete tasks.
Filter tasks by status: All, Completed, or Pending.
Modern UI with CSS styling.

How to Run
Install dependencies:
pip install -r requirements.txt

Run the app:
python app.py

Open in your browser:
http://127.0.0.1:5000

Technologies Used
Backend: Flask (Python)
Frontend: HTML, CSS, Jinja2 Templating
